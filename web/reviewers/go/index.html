JSON Beautifier

Как оставить отзыв

  1. Поставь расширение: Chrome Web Store
  2. Открой любой из примеров — jsonbeautifier.dev/samples/ — или свой JSON-URL
  3. Посмотри на то, о чём спрашивают вопросы ниже
  4. Ответь на вопросы — текст соберётся сам, скопируй его
  5. Вернись на страницу расширения в сторе: вкладка Reviews → Write a review, вставь и отправь
  6. Для взаимного отзыва напиши в тг @minisol

How to leave a review

  1. Install it: Chrome Web Store
  2. Open one of the samples — jsonbeautifier.dev/samples/ — or any JSON URL of your own
  3. Look at whatever the questions below ask about
  4. Answer them — the text assembles itself, then copy it
  5. Back on the store page: Reviews → Write a review, paste and send
  6. For a review in return, message @minisol on Telegram
