Questions people actually ask

Is it free?

Yes. Free, no account, no paid tier, MIT licensed. There is nothing to upsell you.

Does my JSON leave my browser?

No. The extension makes zero network requests — you can verify it in DevTools. The online tool on this page parses and formats in the page itself; nothing is uploaded.

Does it work in Firefox, Edge or Opera?

Edge and Opera install it straight from the Chrome Web Store — same package, same behaviour. Firefox is a different story: it ships its own JSON viewer, and that viewer takes over every JSON page as a privileged document where extensions are not allowed to run. A Firefox build exists and passes Mozilla's checks, but on a default Firefox it would never actually appear, so we do not ship it. If that changes, this answer changes with it.

What's the maximum file size?

The viewer stays interactive into the multi-megabyte range. The online tool warns above 5 MB and refuses above 25 MB, because a browser tab is not a batch processor.

Does it work with local files?

Yes, on file:// URLs — after you tick “Allow access to file URLs” on the extension page. Chrome requires that switch; we cannot flip it for you.

Why does it need host permissions?

To read the JSON a page returns and replace it with a formatted view, the extension has to run on the page you opened. It reads that document and nothing else.

Is it open source?

Yes — github.com/Zumelia/json-beautifier, MIT. The site is open source too.

How do I report a bug?

Use /feedback/ or open a GitHub issue. Both are read by the person who wrote the code.
